# 素材目录

存放适合公开且有权使用的原始照片、Logo 和风格参考图。**目前只有这份说明，没有预置照片。**

| 素材 | 建议文件名 | 使用时说清楚 |
| --- | --- | --- |
| 人物原图 | `retirement-person-original.jpg` | 用作主角；保留面貌、表情等指定特征 |
| 品牌 Logo | `brand-logo.png` | 使用原标识，不自行重画或改字 |
| 风格参考 | `warm-style-reference.jpg` | 只参考配色、字体气质或排版，不替换人物 |

首次练习只需一张人物照片，不必准备齐三种素材。以上名称是示范，文件需要你另行上传。

## 两种素材用法

1. **最省事：直接附在聊天中。**复制模板时写清附件一、附件二分别做什么。
2. **需要复用时：手动上传到本目录。**当前仓库为公开仓库，上传前确认素材适合公开。仍需确认聊天确实读到了图片；不能读取时，直接附图。

不修改原文件来保存新版本。原图保留 `original` 名称，生成图放到 `outputs/`，避免覆盖唯一原图。暂时不需要细分子文件夹。
