# 提示词模板目录

按顺序打开以下文件，复制代码框内的文字，把方括号内容换成实际信息后发到聊天中。

| 阶段 | 模板 | 最少需要填写 |
| --- | --- | --- |
| 第一次出图 | [01-first-draft.md](01-first-draft.md) | 素材用途、主标题、尺寸 |
| 每轮修改 | [02-revision.md](02-revision.md) | 基础版本、具体改动、保留项 |
| 下载交付 | [03-delivery.md](03-delivery.md) | 确认版本、文件名、格式 |

模板可以复制多次，原模板保留不动。不要把方括号占位内容直接当正式文案发出；没有的项目写“无”。

模板只是要求说明，能否读取仓库、编辑图片、导出指定格式，要看当前会话实际提供的工具。若不能直接出图，应明确说明，而不是把排版建议称为成品。

第一次可以直接照着 [完整示例](../examples/first-poster.md) 操作。
