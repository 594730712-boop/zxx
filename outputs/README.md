# 成品输出目录

这里用于**手动归档已经下载的图片**。当前只有说明文件，没有实际海报，也没有自动保存程序。

## 命名约定

| 阶段 | 示例文件名 |
| --- | --- |
| 第一版 | `retirement-cover_v01.png` |
| 修改版 | `retirement-cover_v02.png` |
| 确认成品 | `retirement-cover_final_v02.png` |

成品从 v02 确认就保留 v02；如果继续修改，使用 v03，避免多个文件都叫“最终版”。这些名称仅是示例，不是现有文件。

## 保存步骤

1. 在聊天中选定版本，按 [交付模板](../prompts/03-delivery.md) 核对。
2. 下载原文件到电脑，检查中文、人脸、图片宽高和裁切，按约定命名。
3. 确认可以公开后，在 GitHub 网页进入 `outputs/`，使用上传文件功能添加图片并提交更改。
4. 以后继续改图时，重新附上选定版本与必要原图，不依赖模糊的“上一版”。

需要下载仓库中的单张成品时，打开对应图片文件，使用页面提供的原文件下载入口；不使用网页预览截图代替原图。完整仓库也可通过首页的 **Code → Download ZIP** 下载。

原始素材保留在自己的电脑或 `assets/`，不要用成品覆盖原图。
