# 交付：检查后下载

先填写选中的版本。确认满意后再用，避免误把旧版当成品。

```text
我确认以 [retirement-cover_v02.png] 为最终画面。

请先检查：
1. 画面中文是否与我提供的文案一致，是否有错字、漏字或模糊小字。
2. 人物面貌是否有明显改变，是否出现不自然的轮廓或背景融合问题。
3. 核心标题和人物面部是否在居中3:4安全区内。
4. 文件实际尺寸是否为1080×1920、宽高比是否为9:16。

若有问题，请指出问题并给出修正方案；不要直接把有问题的版本标为合格。
若无问题，不要重新生成一遍以免改变已确认画面。

请提供当前确认版本可下载的PNG原文件。
建议成品名称：[retirement-cover_final_v02.png]。
不能直接导出PNG、设置文件名、调整尺寸或核对某项时，请明确说明实际情况。
```

## 你最后做的两件事

1. 使用聊天里的下载功能，把实际原文件存到电脑；不是只保存聊天截图。打开检查，并在文件属性中核对尺寸。
2. 需要归档时，手动把适合公开的成品上传到本仓库 `outputs/`。聊天附件不会自动同步进仓库。

如果当前会话只能提供文字方案，还没有实际图片可下载，应继续在支持出图的工具中完成，不能把方案当作成品。
